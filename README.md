# Το Κουδούνι

Μια αυτόνομη, στατική ιστοσελίδα για το εβδομαδιαίο πρόγραμμα του 2ου Ημερήσιου Γενικού Λυκείου Ζακύνθου.

## Χρήση

Άνοιξε το `index.html` σε σύγχρονο browser. Δεν απαιτούνται εγκατάσταση, λογαριασμός ή σύνδεση στο διαδίκτυο για τη λειτουργία της εφαρμογής.

## Τι περιλαμβάνει

- Προβολή ωρολογίου ανά τμήμα και ημέρα.
- Καρτέλες εκπαιδευτικών με γνωστικό αντικείμενο και τις ανατεθειμένες ώρες/τμήματα.
- Αναζήτηση εκπαιδευτικού με ή χωρίς τόνους.
- Προσαρμογή για κινητά και tablet.

Τα δεδομένα προέρχονται από το σχολικό πρόγραμμα που ισχύει από 02/11/2026. Η περιγραφή του αντικειμένου βασίζεται στην ειδικότητα που αναγράφεται στο αρχείο· δεν προσθέτει προσωπικά βιογραφικά ή μαθήματα που δεν αναφέρονται εκεί.
